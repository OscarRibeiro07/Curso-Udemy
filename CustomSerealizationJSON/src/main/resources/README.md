## Conteudo de uso(comando)
--------------------------------------------------------------------

***@JsonPropertyOrder({"id", "last_name", "sobrenome", "endereco", "genero"})***
Define ordem de retorno

***@JsonProperty("last_name")***
Modifica nome do retorno

***@JsonIgnore***
Variavel ocm esta notação é ignorada no retorno
